# Security Policy

## Scope

EV is a local-first product. Its security model is described in the README
[Security](README.md#security) section: local services bind to `127.0.0.1` only, require pairing
tokens, restrict allowed origins, and never upload user data.

## Reporting a vulnerability

Please do **not** open a public issue for security vulnerabilities.

- Email: github.sogud@outlook.com
- Include: affected component (desktop / server / CLI / browser extension), reproduction steps,
  and impact assessment.
- You will receive an acknowledgement within 7 days and a remediation timeline after triage.

## Supported versions

Only the latest release on `master` receives security fixes.
