EV（Enhanced Vigilance）是一个本地优先的个人 Agent 工作台：把你已有的编码
Runtime——Pi、Codex、Claude Code、Qoder——放进同一个冷静的界面，桌面 App、浏览器扩展与
CLI 共享同一个只监听 `127.0.0.1` 的本地服务。

## 前置条件

- macOS（桌面端目前只打包 macOS）
- [Node.js](https://nodejs.org) ≥ 22.19
- [pnpm](https://pnpm.io) ≥ 10
- 要运行 Pi / Codex 任务，对应的原生 CLI 需已安装并完成自身登录

## 从源码构建

```bash
git clone https://github.com/sogud/ev.git
cd ev
pnpm install
pnpm run build
```

启动桌面端（会自动拉起本地服务）：

```bash
pnpm run dev:desktop
```

或者打包一个本地 macOS 应用：

```bash
pnpm run pack        # 产物在 release/<version>/mac-arm64/EV.app
```

`pnpm run pack` 同时把 CLI 与 Browser Skill 放进 App Resources。Desktop 启动时会在
`~/.ev/bin/ev` 创建只供当前用户使用的 launcher，下文所有 `ev` 命令都可以直接用它。

## 第一个任务

首次启动会自动创建默认工作区 `~/.ev/workspace`，无需 Onboarding。桌面关闭时，CLI
可以自托管服务：

```bash
ev status                          # 服务状态、LAN/Tailscale URL、token 提示
ev task create --runtime pi        # 创建一个 Pi 任务
ev task prompt <id> "say hi"       # 发送提示
ev task follow <id> --until-idle   # 跟随输出直到任务空闲
```

任务创建后、首条消息之前可以切换 Runtime、模型与思考强度；首条消息之后锁定。

## 检查浏览器桥接

安装并配对浏览器扩展后（见[浏览器扩展安装](/docs/browser-extension)）：

```bash
ev browser check
ev browser session.create --payload '{"url":"https://example.com"}' --compact
```
